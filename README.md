# NotchHub

Нативный хаб для каждого экрана Mac: наведи курсор на верхний край по центру чёлки, чтобы раскрыть панель; уведи — она свернётся. На экране без чёлки используется маленькая капсула. Liquid Glass на macOS 26+, системное размытие на более ранних версиях. Приложение доступно через строку меню.

- Буфер: последние 20, 50 или 100 текстов, картинок и файлов; поиск, копирование и перетаскивание.
- Полка: отдельно до 20 элементов, копии файлов до 30 МБ; папки не поддерживаются.
- Предпросмотр: полные картинки и текст с прокруткой, видео через нативный плеер, другие файлы через Quick Look.
- Заметка с автосохранением; таймер 25/5 минут, пауза и звук. Отсчёт сохраняется после перезапуска.
- Переключение буфера: ⌘⌥V, затем держи ⌘ и нажимай V. Отпусти ⌘ для выбора, нажми обычное ⌘V для вставки. Если сочетание занято другим приложением, появится сообщение.

Булавка удерживает панель открытой. Пауза останавливает захват нового содержимого. Корзина после подтверждения очищает историю и текущий буфер macOS; полка и заметка сохраняются.

Требования: macOS 14+, Xcode 26 / соответствующие Command Line Tools или новее для сборки SwiftUI Liquid Glass. Внешних зависимостей нет; сборка для текущей архитектуры Mac.

```sh
git clone https://github.com/DmitryBarmin/NotchHub.git NotchHub
cd NotchHub
swift test
bash build.sh
```

Скрипт только собирает `dist/NotchHub.app`, установленное приложение не меняет. Для установки закрой старый экземпляр и перенеси bundle в `/Applications/NotchHub.app`, затем открой двойным кликом. ZIP-релиз содержит только приложение — также перенеси его в Applications. Подпись локальная ad hoc, нотариального заверения Apple нет. Для автозапуска добавь `/Applications/NotchHub.app` в «Системные настройки → Основные → Объекты входа».

История, заметка и копии файлов хранятся локально в `~/Library/Application Support/NotchHub/`; обычный захват буфера работает без сети и разрешения Accessibility. Сеть используется только при запрошенной передаче ссылкой. Эти данные не входят в исходники и релиз. Метки Concealed/Transient/AutoGenerated игнорируются; немаркированный чувствительный текст может попасть в историю. Очистка удаляет только копии приложения. Размер одного элемента — до 30 МБ. Захват буфера начинается с изменений после запуска, а не с уже существовавшего содержимого. Управления системной громкостью и музыкальными приложениями нет.

## Скриншотер (1.3)

Пункт «Сделать скриншот» в меню значка верхней строки, кнопка видоискателя в панели или ⌘⇧9 запускает захват области на любом мониторе. Выделите область мышью; тяните углы для обрезки или перемещайте область инструментом обрезки. Двойной клик / ⌘A — весь экран. Компактная вертикальная панель содержит карандаш, линию, стрелку, рамку, овал, маркер, текст, непрозрачное скрытие области и отмену. Цвет и толщина меняются рядом. Нижняя панель: OCR, PNG-сохранение, копирование, отмена захвата. Все кнопки — значки с подсказками. После отпускания мыши PNG автоматически копируется в буфер; обрезка, рисунки и отмена обновляют эту копию, не закрывая редактор.

⌘C / Enter — копировать, ⌘S — сохранить PNG, ⌘Z — отменить рисунок, ⌘T — распознать текст, Esc — закрыть. OCR выполняется локально Apple Vision (русский / английский), результат можно выделять, редактировать и копировать. Для скриншотера macOS требует **Запись экрана**; разрешение выдаётся пользователем в Системных настройках. После изменения разрешения перезапустите NotchHub. Скриншоты остаются на Mac, пока пользователь сам не выберет их для передачи.

При переключении буфера через ⌘⌥V удерживайте ⌘⌥B для предпросмотра выбранного элемента. Отпускание B или модификаторов скрывает предпросмотр; отпускание ⌘ завершает выбор как раньше. Настройки → Клавиши: отдельное переназначение буфера, удерживаемого предпросмотра, скриншотера и каждой команды редактора. Если глобальное сочетание занято, приложение сообщает об этом и сохраняет прежнюю комбинацию.

На Command Line Tools с SDK 27 без плагина SwiftUI можно выбрать установленный SDK 26.5:

```sh
NOTCHHUB_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk bash build.sh
```

Для `swift test` требуется полный Xcode с XCTest. Новые проверки покрывают Retina-обрезку, направление выделения, экспорт скрытых областей, конфликт клавиш и локальное OCR.

На Mac без XCTest доступны 19 локальных проверок без захвата личного экрана:

```sh
NOTCHHUB_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk bash scripts/check-screenshot.sh
```

Настройки → Основные → Кнопка скриншотера: можно показать или скрыть кнопку в панели, не отключая сочетание клавиш и пункт меню. Панели захвата используют Clear Liquid Glass с полупрозрачной светлой обводкой.

Кнопка палитры в боковой панели открывает стандартный выбор цвета macOS. Цвет применяется к новым рамкам, овалам, стрелкам, линиям, маркеру и тексту; непрозрачное скрытие области остаётся чёрным.


## Возможности 2.0

Настройки → Возможности: десять независимых переключателей. Выключение скрывает действия и освобождает назначенные им глобальные клавиши; сохранённые данные остаются. Настройки → Клавиши: команды назначаются отдельно, конфликт сохраняет прежнюю комбинацию. Настройки → Общие → Кнопки левого меню: можно закрепить или убрать быстрые действия новых функций. Кнопки скрываются при отключении функции; выбор сохраняется. Длинное левое меню прокручивается.

- Избранное и текстовые шаблоны защищены от вытеснения обычной историей.
- Текстовые действия: убрать оформление, сменить раскладку или регистр, форматировать JSON, убрать метки отслеживания из ссылки.
- Отдельный предпросмотр: до пяти окон с независимыми копиями содержимого.
- OCR изображений выполняется локально Apple Vision.
- Множественный выбор: объединение текстов, копирование нескольких файлов, перетаскивание отдельных элементов.
- Приватность: пауза захвата, исключения приложений по bundle ID, срок хранения и общий лимит копий. Защищённые метки буфера игнорируются.
- Рабочие наборы разделяют полку и заметку; история буфера общая.
- История скриншотов хранит до 20 выбранных фрагментов / 200 МБ. Можно открыть и продолжить редактирование. Непрозрачное скрытие необратимо в сохранённых пикселях.
- Несколько именованных таймеров сохраняют дедлайны после перезапуска.
- QR для текста и передачи; ссылка через временный сервер, в том числе отправленная AirDrop.

### Передача между Mac

На обоих Mac нужен NotchHub 2.0. Выбери изображения в истории → «Передать» → получи ссылку → скопируй её или отправь через AirDrop. Получатель открывает приглашение в NotchHub, видит содержимое и подтверждает приём. Три выбранных скриншота добавляются как **три отдельных изображения** в историю получателя; существующие записи не подменяются системным файлом, папкой или архивом. Системный буфер macOS получает конкретный элемент, когда получатель его копирует.

Передача через AirDrop отправляет ссылку-приглашение, поэтому для загрузки содержимого обоим Mac нужен интернет. Данные шифруются AES-256-GCM до загрузки; ключ находится во фрагменте ссылки и не отправляется серверу. Ссылку следует передавать только получателю: она даёт доступ к содержимому. Сервер хранит шифротекст один час, общий лимит 200 МБ, до 20 передач; максимум 20 элементов / 60 МБ исходного содержимого на одну передачу. Ограничения проверяются до импорта; при ошибке ни один элемент пакета не добавляется.

В Настройки → Передача задаются HTTPS-адрес сервера и ключ отправки, хранящийся в Keychain. Для приёма приглашения ключ отправки не нужен. Реализация сервера и развёртывание: [server/notchhub-share/README.md](server/notchhub-share/README.md).

### Архитектура и проверки

`HubPreferences` управляет функциями и хранением; `CommandShortcuts` регистрирует только включённые команды. `HubStore` владеет историей, избранным, шаблонами и рабочими наборами. `ScreenshotLibrary` хранит только выбранные области отдельно от захвата экрана. `TimerLibrary` использует сохранённые дедлайны и один общий тик только при активном отсчёте. `HubWindows` освобождает содержимое при закрытии; отдельные предпросмотры владеют собственными временными копиями. `ClipboardTransfer` отделяет шифрование и транспорт от атомарного импорта в `HubStore`.

`swift test` проверяет миграцию истории, лимиты, избранное, рабочие наборы, таймеры, OCR, скриншоты, клавиши, отмену передачи и импорт отдельных изображений. Сервер: `python3 -m unittest discover -s server/notchhub-share`. Live-тест передачи включается только с `NOTCHHUB_TRANSFER_KEY_FILE` и использует синтетические изображения. `NotchHub --demo` открывает изолированную демонстрационную историю с тремя тестовыми скриншотами, заметкой, шаблоном и таймерами.
